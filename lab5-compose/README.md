# Лабораторная работа №5: Многоконтейнерная архитектура (Docker Compose)

Проект представляет собой микросервисную архитектуру, состоящую из трёх контейнеров:
- **api**: REST API на базе Python (Flask)
- **db**: База данных PostgreSQL 15 (Alpine)
- **redis**: Сервер кэширования Redis 7 (Alpine)

## 🛠 Требования к окружению

- **Git** / Git Bash
